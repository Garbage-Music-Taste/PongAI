# Pong Reinforcement Learning Agent

This repository contains the original one-environment Pygame DQN and a new
Torch-native vectorized trainer intended for modern CPUs and GPUs.

## Recommended trainer

The new trainer fixes the main performance and learning problems in the original design:

- thousands of Pong environments advance in one Torch batch;
- the environment and replay buffer stay on the selected device;
- CUDA, Apple MPS, and CPU are selected automatically;
- paddles are clamped to the board;
- ball speed and state normalization are consistent;
- launch directions are symmetric;
- the network is a small dueling DQN rather than an unnecessarily wide MLP;
- action selection uses Double DQN targets and Huber loss;
- rewards include a return reward and modest alignment shaping;
- opponent speed follows a curriculum before evaluation against the full-speed reflex agent;
- evaluation is greedy and separate from epsilon-greedy training.

The default policy has roughly 18,000 parameters. Pong only has seven state
features and three actions, so increasing parameter count is generally less
useful than generating more varied experience.

## RTX 5070 Ti setup

The RTX 5070 Ti is an NVIDIA Blackwell GPU. Install a current PyTorch CUDA build
that supports the card. Use the command generated by the official PyTorch
installation page, then install the remaining dependencies:

```bash
pip install torch --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements.txt
```

Verify the install:

```bash
python -c "import torch; print(torch.__version__); print(torch.version.cuda); print(torch.cuda.get_device_name()); print(torch.cuda.get_arch_list())"
```

## Train

A full desktop run:

```bash
python train_vectorized.py \
  --device cuda \
  --num-envs 4096 \
  --batch-size 2048 \
  --total-transitions 5000000 \
  --output pong_vectorized.pth
```

The defaults choose 4,096 environments on CUDA and 512 on CPU/MPS. Start with
`--total-transitions 500000` as a quick hardware and learning sanity check.

Useful overrides:

```bash
python train_vectorized.py --device cpu --num-envs 256 --batch-size 512 --total-transitions 200000
python train_vectorized.py --hidden-dim 64 --total-transitions 1000000
```

## Watch the trained policy

```bash
python play_vectorized.py --model pong_vectorized.pth
```

## Tests

```bash
pytest -q
```

## Original agent

The original scripts remain available for comparison. They use one Pygame
environment and one tiny gradient update per frame, which is simple but leaves
modern hardware mostly idle. The original README's reported result is not
directly comparable to the vectorized trainer unless both checkpoints are
evaluated in the same environment with epsilon set to zero.
